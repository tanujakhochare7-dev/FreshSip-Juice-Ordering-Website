# FreshSip – Juice Ordering Website

FreshSip is a responsive static juice ordering website developed using HTML, CSS and JavaScript.

## Features

* Modern responsive juice shop design
* Juice product listing
* Search juices by name
* Filter products by category
* Add products to cart
* Increase and decrease quantity
* Remove products from cart
* Automatic cart total calculation
* LocalStorage for cart data
* Order form with customer details
* Responsive mobile navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## JavaScript Concepts Used

* DOM Manipulation
* Event Listeners
* Arrays and Objects
* `filter()`
* `find()`
* `forEach()`
* LocalStorage
* Dynamic HTML rendering
* Form handling

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

This project was developed as a front-end portfolio project to demonstrate responsive web design, JavaScript functionality, DOM manipulation and localStorage.
